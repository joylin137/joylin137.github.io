- About Me: `about-me.html`

All images, fonts, CSS, icons and five demonstration videos are local. The site does not load Squarespace JavaScript, analytics or account services. Email, LinkedIn, Figma and the existing Dropbox game download remain external links.

## Publish with GitHub Pages

1. Create a public GitHub repository named `YOUR-USERNAME.github.io`.
2. Upload the contents of this folder to the repository root, including `index.html` and the image, font and media files. Do not upload the ZIP file itself.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, then **main** and **/(root)**, and save.
5. The website will appear at `https://YOUR-USERNAME.github.io/` after GitHub completes deployment.

A public repository is required for GitHub Pages on GitHub Free. HTML and asset source files will also be public.

Alternatively, any public repository can host this folder at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`; relative links work at either address.

## Edit and preview

Text and layout can be edited in the relevant HTML file. Shared custom styles are in `static.css`; navigation code is in `main.js`. Existing section grid styles are retained in each HTML page to preserve desktop and mobile layout.

Open `index.html` in a browser for a quick preview, or run `python -m http.server 8000` in this folder and visit `http://localhost:8000`.

The Squarespace visual editor does not transfer to GitHub Pages. This copy preserves the published pages rather than an editable Squarespace account.

Content and layout were copied from the owner's publicly accessible site supplied in the migration request. Review the migrated site before ending the Squarespace subscription.
